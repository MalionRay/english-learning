# English Learning

## v0.9.1：聽力理解（取代逐字聽寫）
- 聽句子（可重播、🐢 慢速），用中文寫出或用鍵盤麥克風說出意思，由 AI 判斷是否聽懂（70 分以上算懂）
- 不想寫可以直接「看答案」自己判斷：聽懂／部分懂（明天再聽）／沒聽懂
- 離線時先記錄，之後連網自動批改

## v0.9.0：聽寫
- 練習多了「聽寫」：播放題庫裡的句子（可重播、🐢 慢速），打出聽到的內容
- 逐字比對：綠色是對的、紅底是漏掉、刪除線是寫錯或多寫；大小寫與標點不算錯；90% 以上算答對
- 句子第一次播放會用一次 Gemini 語音額度，之後用存好的錄音

## v0.8.0：生字本、點字加入、學習統計
- 生字本：自動收集標記的生字、答錯過的字，以及自己點選加入的字；可搜尋、移除
- 練習時句子裡的每個字都能點：唸出來、看中文、加入生字本
- 練習多了「生字複習」：看英文回想中文，翻面後選記得／不記得
- 學習統計：連續天數、今天作答數、最近 30 天長條圖、各題型正確率

## v0.7.3：依回報原因修正
- 答案標錯：AI 重新判斷答案；若原答案其實正確，會說明理由並自動恢復
- 兩個以上都對：換掉干擾選項；看不懂：改寫得更清楚；翻譯或解釋有錯：只修中文，練習進度保留

## v0.7.1：回報後自動補修正題
- 回報時 AI 會依原因出一題同類型的修正版；還沒作答就直接換上，已作答則之後當新題出現
- 沒網路時先跳過，主畫面回報清單可按「重新出這題」

## v0.7.0：避免出問題
- 練習時「⚑ 回報」：題目有錯就回報，之後所有人都不再出這題；主畫面可看被回報的題目並恢復
- 練習畫面頂端顯示目前使用者
- 每 7 天自動備份答題紀錄、文章與題庫到 backup/<裝置ID>/（保留 4 份）；設定裡可「立即備份」
- 按「結束並同步」時若自動同步正在跑，會等它結束後再同步一次

## v0.6.1：克漏字改成打字作答

- 拼錯時顯示正確拼法，只差一個字母會標「拼字差一點」

## v0.6.0：練習更好用

- 單字、句子、題目、選項旁都有「中」按鈕可看中文；作答前看了，答對只算練習（不拉長間隔）
- 閱讀理解的文章可逐段看中文
- 選擇題與翻譯題都有「我不知道」
- 新出的題庫內建翻譯（離線可看）；舊題庫按「中」時即時翻譯並記住

## v0.5.0：練習

- 選擇題點了立刻顯示對錯與解釋；翻譯題由 Gemini 批改（離線時先記錄，之後自動批改）
- SRS：答對間隔拉長（1→3→7→14…天），答錯隔天再出；生字間隔拉得比較慢；答錯的題目在這場最後再練一次

## v0.4.0：更自然的發音
- 點 🔊 依序嘗試：已存的錄音 → 字典真人錄音（單字）→ Gemini 自然語音 → 系統語音
- 錄音存在 english/audio 並同步，之後在任何裝置離線也能播
- Gemini 語音用免費額度：收到「超過限制」當天停用；設定可限制每天最多幾段（預設 100）
- 驗證面板可分別測試系統語音、Gemini 語音、字典發音

## v0.3.0：生字標記、音標與朗讀
- 匯入時填「我不會的字」，或在文章裡用 ==字== 標記；標記的字一定會出題（題庫中標 ⭐生字）
- 單字題附 IPA 音標；題庫裡的英文單字與句子點一下就朗讀（系統語音，可離線）
- 閱讀模式下點文章裡的螢光筆生字也會朗讀
- 設定可選朗讀語音與速度（每台裝置各自設定）；驗證面板有「測試發音」

## v0.2.0：文章匯入與 AI 出題
- 左側書本圖示開啟主畫面 →「匯入文章」貼上英文文章，選程度（成人／小孩）
- 「出題」：依文章長度產生 8～20 題（單字、克漏字、閱讀理解、句子翻譯），解釋為繁體中文
- 題庫寫在 english/bank/<id>.md，來源筆記標 status: generated 防重複；只能在匯入的裝置出題
- 出題完成後自動同步（可在設定關閉）

## 驗證外掛（v0.1.0 起）

只做五件事：
1. 首次啟動產生裝置 ID（例如 `win-1a2b3c4d`），存本機 localStorage。
2. 「記一筆」：往 `logs/<user>/<deviceId>.jsonl` append 一行（含 UUID、時間戳）。
3. 「合計」：讀取磁碟上所有 log，用 UUID 去重後計算；列出不符命名規則的檔案（衝突副本）。
4. 「測試 API」：用 requestUrl() 呼叫 Gemini，金鑰取自 SecretStorage；usage 寫進 log。
5. 「測試麥克風」：getUserMedia({ audio: true })，結果寫進 log。

另外有「立即同步」按鈕（觸發 Remotely Save），以及每台裝置的除錯紀錄 `debug/<deviceId>.md`。

開啟方式：左側功能列的燒瓶圖示，或指令面板搜尋「English Learning」。
