# English Learning

## v0.16.3：對話更自然、語音額度
- AI 對話改成像朋友聊天（成人是 Alex、小孩是 Mia）：針對你說的細節回應、會分享自己的經驗、不再每句都是「That's awesome!」開頭
- 快速模型改用正式版 gemini-3.1-flash-lite
- Gemini 自然語音免費版每天只有 10 段（所有裝置共用）：每日上限預設改成 10；預先產生錄音改成只下載字典真人錄音，把額度留給對話；用完時提醒一次並改用系統語音
- 系統語音會自動挑 iPad 上下載的高品質（Premium／優化）英文語音

## v0.16.2：對話變快
- 速度測試發現慢的是模型本身：gemini-3.5-flash-lite 回一句對話要 22～25 秒，gemini-3.1-flash-lite-preview 只要約 1.6 秒（同樣免費）
- 新增「快速模型」設定（預設 gemini-3.1-flash-lite-preview），用在英文對話、批改、翻譯、查原形；不能用時自動改回主要模型。出題、拍照辨識仍用主要模型
- Gemini 語音遇到「每分鐘上限」不再整天停用，只暫停一分鐘；對話在用語音時，背景的預先產生錄音會先讓路

## v0.16.1：預設自然語音、AI 速度測試
- 對話的 AI 回覆預設用 Gemini 自然語音朗讀；第一句先產生先唸，不用等整段；額度用完或失敗時自動改用系統語音
- 對話開始畫面新增「AI 速度測試」：量這台裝置呼叫 Gemini 各步驟要多久，找出對話為什麼慢

## v0.16.0：對話的語音
- **AI 回覆自動唸出來**：預設用系統語音（立即），也可以在對話開始畫面改成自然語音（慢幾秒、用每日額度）或關閉；對話上方的 🔊／🔇 可以隨時切換
- **🎤 用說的**：按 🎤 開始說、按「說完了」送出；錄音直接交給 AI 聽，可以英文夾中文，比 iPad 鍵盤聽寫準；你說的內容（保留原本的文法）會顯示出來，說錯照樣會被糾正
- **回應變快**：超過 8 秒沒回應會自動再送一次、取先回來的；45 秒還沒回就提示重送；每次回應花多久會記下來

## v0.15.0：不會的句子變練習、對話裡自然複習
- **答錯的句子自動進句子本**：克漏字答錯或按「我不知道」（包括以前的紀錄）會把整句放進句子本，翻譯題答錯、聽力沒聽懂的句子也是；到「練習 → 句子」看中文說英文
- **對話中的 SRS 複習**：開始英文對話時，挑出到期的生字和句子（上次答錯的優先），AI 會在聊天中自然用到、並問你問題讓你有機會用；畫面上方列出這次會複習的項目，AI 用到的字有虛線底線，你用對了就打勾、算一次複習（SRS 排程往後推）。開始畫面可以關掉

## v0.14.0：學習效果
- **錯誤模式分析**：在「學習統計 → 分析我的常見錯誤」。AI 會看最近 60 天的翻譯、句子、克漏字和對話裡的錯誤，找出反覆犯的錯（例如過去式、冠詞），說明規則並出練習句。勾選的練習句可以加入句子本，報告存在 english/reports
- **同一個字的不同形態合併**：go、went、going 在生字本裡是同一筆，卡片上會標「也包含：went、going」。原本分開的複習進度也會一起算
- **拍照匯入**：匯入視窗按「📷 拍照／選照片」，可以拍書本或講義（可一次選多頁），AI 會辨識英文。照片上用螢光筆、底線或圈起來的字，會自動填進「我不會的字」

## 驗證外掛（v0.1.0 起）

只做五件事：
1. 首次啟動產生裝置 ID（例如 `win-1a2b3c4d`），存本機 localStorage。
2. 「記一筆」：往 `logs/<user>/<deviceId>.jsonl` append 一行（含 UUID、時間戳）。
3. 「合計」：讀取磁碟上所有 log，用 UUID 去重後計算；列出不符命名規則的檔案（衝突副本）。
4. 「測試 API」：用 requestUrl() 呼叫 Gemini，金鑰取自 SecretStorage；usage 寫進 log。
5. 「測試麥克風」：getUserMedia({ audio: true })，結果寫進 log。

另外有「立即同步」按鈕（觸發 Remotely Save），以及每台裝置的除錯紀錄 `debug/<deviceId>.md`。

開啟方式：左側功能列的燒瓶圖示，或指令面板搜尋「English Learning」。
